# SKALA 법인카드(법카) 사용 규정 (2026-08 개정)

## 1. 사용 가능 항목

| 항목 | 사용 가능 여부 | 비고 |
| --- | --- | --- |
| 팀 회식(식사) | 가능 | 팀장 또는 승인자 사전 승인 필요 |
| 팀 회식(주류) | 조건부 가능 | 2장 주류 결제 규정 참조 |
| 개인 식사 | 불가 | 출장 중 식대는 별도 규정 적용 |
| 사무용품 구매 | 가능 | 별도 한도 적용(본 문서 범위 외) |

## 2. 주류 결제 규정

- 회식 1건당 주류 결제 금액은 전체 결제 금액의 **50%를 초과할 수 없다**.
- 주류만 단독으로 결제하는 것은 허용되지 않으며, 반드시 식사와 함께 결제해야 한다.
- 2차 이상 주류 전문점 결제는 팀장 승인 외 **부서장 사전 승인**이 추가로 필요하다.

## 3. 심야 회식 규정

- 오후 10시 이후 결제 건은 "심야 회식"으로 분류되며, 팀장 승인과 별도로 **사유 소명**을 등록해야 한다.
- 자정(00:00) 이후 결제는 원칙적으로 법카 사용이 제한되며, 부득이한 경우 사후 소명 후 부서장 승인을 받아야 한다.
- 심야 회식 빈도가 월 2회를 초과하는 팀은 분기별 사용 내역 점검 대상이 된다.

## 4. 카드 사용자 및 결제 방식

- 법카는 팀장 또는 팀 내 지정된 법카 관리자만 결제할 수 있다.
- 결제 후 즉시(또는 익일 근무일까지) 회식비 사용 등록을 완료해야 한다.
- 개인 카드로 선결제 후 환급받는 방식은 원칙적으로 허용되지 않는다.
