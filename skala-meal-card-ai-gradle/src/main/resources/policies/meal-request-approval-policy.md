# SKALA 회식비 사전 신청·승인 규정
**2026-08 개정**

## 1. 신청 원칙

- 법인카드로 회식비를 결제하려면 결제 전에 회식 신청을 등록하고 승인을 받아야 한다.
- 승인 없이 결제한 건은 사후 소명 대상이 되며, 정당한 사유가 없으면 회식비 지원이 반려될 수 있다.

## 2. 신청 시점

- 신청 의사를 밝히면 접수번호는 즉시 발급되며, 사전 신청서(3항의 상세 항목)는
  최소 회식 1일 전까지 작성을 완료해야 한다.
- 당일 신청은 팀장 직권으로 예외 승인할 수 있으나, 사유를 반드시 기재해야 한다.

## 3. 신청 필수 항목

아래 항목은 접수 시점이 아니라 사전 신청서 작성 시점에 채운다.
접수번호만 발급된 상태에서는 매니저가 승인할 수 없다.

| 항목 | 필수 여부 | 설명 |
|---|---|---|
| 팀명 / 신청자 | 필수 |  |
| 회식 예정일 | 필수 |  |
| 참석 인원 수 | 필수 | 예상 한도 계산에 사용 |
| 회식 사유 | 필수 | 예: "프로젝트 마감 기념", "신규 입사자 환영" |
| 예상 사용 금액 | 필수 | 참석 인원 × 1인당 한도 기준 자동 계산 |
| 심야·주류 예정 여부 | 조건부 필수 | 해당 시 사유 함께 기재 |

## 4. 승인 절차

1. 신청자가 신청 의사를 밝히면 즉시 접수번호가 발급되고 팀장에게 신청 사실이 전달된다.
2. 신청자는 접수번호를 이용해 사전 신청서(3항의 상세 항목)를 작성한다.
3. 사전 신청서 작성이 완료되어야 팀장(또는 승인자)이 신청 내용을 검토·승인할 수 있다.
   사전 신청서가 작성되지 않은 접수 건은 승인 대상이 아니다.
4. 예상 금액이 팀 잔여 예산 이내면 팀장 승인만으로 처리된다.
5. 예상 금액이 팀 잔여 예산을 초과하면 부서장 승인이 추가로 필요하다.
6. 승인이 완료되면 신청 건에 승인 번호가 발급되며, 해당 번호로 법카 결제가 가능해진다.

## 5. 승인 후 처리

- 승인된 예상 금액과 실제 결제 금액의 차액이 10%를 초과하면 결제 후 별도 소명이 필요하다.
- 승인 유효 기간은 신청일로부터 3일이며, 기간 내 결제하지 않으면 승인이 자동 취소된다.

## 6. 반려 사유

- 팀 잔여 예산 부족
- 참석 인원 대비 예상 금액이 한도를 크게 초과
- 신청 필수 항목 누락
