# SKALA 회식비 한도 규정
**2026-08 개정**

## 1. 1인당 회식비 한도

| 구분 | 1인당 한도(1식 기준) | 비고 |
|---|---:|---|
| 평일 일반 회식 | 40,000원 | 초과 시 팀장 소명 필요 |
| 신규 입사자 환영회 | 50,000원 | 분기 1회 한정 |
| 프로젝트 종료 회식 | 60,000원 | 사전 예산 신청 필요 |

- 위 한도는 주류 포함 금액 기준이다.
- 참석자 수 대비 한도를 초과하는 결제는 팀 예산에서 자동 차감되지 않고 사후 승인 대기 상태로 전환된다.

## 2. 팀 예산 산정 기준

- 팀별 회식비 예산은 분기 단위로 배정되며, 팀 인원 수 × 분기 기준액으로 산정한다.
- 분기 기준액은 1인당 월 30,000원(분기 90,000원)이다.
- 팀 예산은 분기 종료 시 이월되지 않으며, 미사용분은 소멸된다.

## 3. 예상 한도 계산 방식

- 예상 사용 한도 = 참석 인원 × 1인당 한도(회식 유형별)
- 팀 잔여 예산보다 예상 사용 한도가 큰 경우, 회식비 사용 등록 시 경고가 표시되며 부서장 승인이 추가로 필요하다.

## 4. 초과 시 처리

- 한도를 초과한 결제 건은 초과분에 대해 팀장 명의로 소명 사유를 등록해야 한다.
- 반복적인 한도 초과(월 3회 이상)는 다음 분기 팀 예산 산정 시 반영될 수 있다.
